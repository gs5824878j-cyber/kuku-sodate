# 九九そだて Ver.1

子ども向けの九九学習・育成Webアプリです。

## 主な機能

- 九九を見て覚える・答えを隠して確認・9問テスト
- 今日の課題と復習、苦手問題の確認
- 1・3・5分から選べるチャレンジ
- 学習ポイント、アイテム購入、キャラクターの育成・進化
- 保護者向けの正答率・苦手マップ

## データ保存

学習記録・設定・育成データはブラウザのlocalStorageに保存されます。
端末・ブラウザ・公開元が変わると記録は共有されません。ブラウザのデータを削除すると記録も消えます。
保存用の内部キーは既存版との互換性のため維持しています。

## 公開方法

外部APIキー不要。index.html・style.css・app.jsを同じ場所に置くだけで動作し、GitHub Pagesで公開可能です。

4ファイルをリポジトリのルートに配置し、Settings → Pagesで「Deploy from a branch」、main、/(root)を選択します。
